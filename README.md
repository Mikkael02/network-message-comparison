# network-message-comparison

Projekt do pracy magisterskiej:
„Analiza porównawcza metod wymiany komunikatów w aplikacjach sieciowych z uwzględnieniem wydajności i sposobów walidacji danych”.

## Zakres
- REST / HTTP
- WebSocket
- gRPC

## Cel
Porównanie metod komunikacji pod kątem:
- wydajności,
- narzutu komunikacyjnego,
- walidacji danych i komunikatów.
